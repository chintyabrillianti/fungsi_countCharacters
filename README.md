# fungsi_countCharacters

Program Python untuk menghitung karakter dalam sebuah teks.

## Aturan Perhitungan
- Huruf kecil (a-z) dihitung.
- Angka (0-9) dihitung.
- Huruf kapital (A-Z) diabaikan.
- Spasi diabaikan.

## Teknologi
- Python 3

## Contoh Input
Latihan BTPN di 2026

## Karakter yang Dihitung
a, t, i, h, a, n, d, i, 2, 0, 2, 6

## Hasil
Jumlah karakter: 12

## Fungsi Utama
Fungsi count_characters(teks) menggunakan:
- islower() untuk menghitung huruf kecil.
- isdigit() untuk menghitung angka.
